# QuantMind 2.0 Project Knowledge

This directory is the repository-local, versioned knowledge base for
QuantMind 2.0. Start with [`context/CONTEXT_INDEX.md`](context/CONTEXT_INDEX.md).

Authority order:

1. Project Charter, Architecture v1, and accepted ADRs define approved intent.
2. Current code and tests define current behavior.
3. Immutable Implementation Runs explain how behavior changed.
4. Current State, Component Catalog status, and Handoff are derived summaries.
5. Historical chat is not an authoritative project source.

Research Memory, Project Architecture Memory, and the Implementation Ledger
are separate systems and must not substitute for one another.
